MORE THAN WORDS — LAYERED FEATURE STORY
======================================

PROJECT FILES
-------------
index.html                 Editorial feature story about Diné Bizaad.
styles.css                 Responsive layout, positioning, layer tokens, and shape enhancements.
composition-plan.html      Element-by-element rationale and fallback plan.
SUPPORT-AND-FALLBACK.md    MDN references and support/fallback notes.
TEST-RECORD.md             Required test checklist and evidence log.
feature.svg                Abstract feature illustration supplied with the starter.
portrait.svg               Abstract portrait-style illustration supplied with the starter.

COLOR THEME
-----------
The editorial palette pairs turquoise with warm sandstone and muted clay.
It is inspired by turquoise and the regional landscape, but is not presented as
a universal Indigenous palette or as a definitive statement about Diné art.
The SVG illustrations use the same palette.

OPEN THE PROJECT
----------------
1. Keep all files together in the same project folder.
2. Open index.html in a browser, or use VS Code Live Server.
3. Do not move the SVG files into another folder unless you also update their src paths.
4. Open composition-plan.html for the design rationale and element fallbacks.

BUILD BOUNDARIES
----------------
- The supplied assessment starter is the scaffold for this project.
- The story uses normal document flow for prose and source order.
- CSS Grid handles the main page regions; no paragraphs are positioned into columns.
- Positioning is limited to the anchored header badge, bounded sticky navigation, and the documented pull-quote overlap.
- The story contains no fixed-height prose boxes and no essential content inside clipped areas.
- clip-path and shape-outside are progressive enhancements with readable fallbacks.
- Layer values are documented tokens in :root; avoid adding arbitrary z-index values.
- Native HTML and CSS only; no JavaScript is required.

WORKFLOW BEFORE SUBMISSION
--------------------------
1. Read and revise the story in your own voice. Verify all factual claims against the linked sources in index.html.
2. Keep the L1-L6 evidence labels visible.
3. Review composition-plan.html and update it if you change any enhanced element.
4. Follow SUPPORT-AND-FALLBACK.md and TEST-RECORD.md; do not mark a test passed until you have performed it in a browser.
5. Run HTML and CSS validation and save screenshots of the required viewport, zoom, keyboard, growth, sticky, pointer, fallback, and stacking-context tests.
6. Replace or retain the supplied illustrations only with accurate alt text, captions, and asset credits.
7. Add your repository URL and published starter-derived page URL to the submission notes when available.
8. Keep the AI disclosure accurate and follow your course's disclosure policy.

CONTENT AND ASSET NOTES
-----------------------
The article focuses on Diné Bizaad and Navajo Nation initiatives. It does not claim to speak for Diné people.
